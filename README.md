## ━━━━━━━ THE ART OF TASTE ━━━━━━━

*A refined interface. A memorable atmosphere. A digital experience inspired by the world of fine dining.*

</div>

**Delici** is a restaurant website project that combines elegant visual presentation with modern front-end technologies. Inspired by premium dining experiences, the design focuses on atmosphere, visual storytelling, responsive layouts, and interactive details.

## ✧ FEATURES

- **Responsive Interface** — layouts designed for different screen sizes.
- **Interactive Components** — dynamic behavior powered by JavaScript and jQuery.
- **Elegant Visual Presentation** — food-focused imagery and a cohesive design direction.
- **Smooth Animations** — visual transitions that enrich the user experience.
- **Reusable Styling** — organized styles using Sass.
- **Bootstrap Integration** — responsive layouts and UI components.
